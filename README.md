# লেখাঘর (Lekhaghor)

বাংলাদেশ-কেন্দ্রিক লেখালেখি প্ল্যাটফর্মের বেসিক ফ্রন্টএন্ড স্ট্রাকচার — Next.js + Tailwind CSS দিয়ে বানানো।

## পেজসমূহ
- `/` — হোমপেজ (ফিচার্ড লেখা + সাম্প্রতিক লেখার গ্রিড)
- `/read/[slug]` — লেখা পড়ার পেজ
- `/profile/[username]` — লেখকের প্রোফাইল
- `/write` — লেখা তৈরির এডিটর
- `/login` — লগইন / সাইনআপ

এখন সবকিছু `lib/sample-data.ts`-এর মক ডেটা দিয়ে চলছে। পরের ধাপে এটাকে Supabase (auth + database + file storage) দিয়ে রিপ্লেস করা হবে।

## লোকালি চালানো
```bash
npm install
npm run dev
```
তারপর ব্রাউজারে `http://localhost:3000` খুলুন।

## GitHub + Vercel-এ ডিপ্লয়
1. এই ফোল্ডারটা একটা GitHub রিপোতে পুশ করুন।
2. [vercel.com](https://vercel.com)-এ গিয়ে GitHub দিয়ে সাইন-ইন করে রিপোটা ইমপোর্ট করুন।
3. Vercel অটোমেটিক Next.js ডিটেক্ট করে বিল্ড করে দেবে — কোনো এক্সট্রা কনফিগ লাগবে না।
4. পরের প্রতিটা `git push` অটোমেটিক নতুন ডিপ্লয় ট্রিগার করবে।

## পরের ধাপ (এখনো বাকি)
- Supabase দিয়ে আসল অথেনটিকেশন ও ডেটাবেজ যুক্ত করা
- রিচ টেক্সট এডিটর (যেমন TipTap) দিয়ে `/write` পেজ আপগ্রেড করা
- ফাইল আপলোড আসল স্টোরেজে (Supabase Storage) সংযুক্ত করা
- ক্লাসিক বই লাইব্রেরি সেকশন (`/library`) — শুধুমাত্র পাবলিক ডোমেইন লেখকদের রচনা দিয়ে
